Panduan Ganti Password & SSID Wi-Fi

Langkah mudah mengamankan jaringan internet Jarvis Network Anda dengan memperbarui nama Wi-Fi dan kata sandi (Modem F477).

Pendahuluan

Mengganti password Wi-Fi dan SSID secara berkala sangat penting untuk menjaga keamanan jaringan Anda. Dalam tutorial ini, Anda akan belajar cara login ke modem, mengubah SSID (nama jaringan Wi-Fi), serta mengganti password Wi-Fi Anda.

1

Login ke Modem/Router

Buka browser (misal: Google Chrome) dan ketik IP Address berikut di address bar (bagian atas), lalu tekan Enter / Cari.

192.168.1.1

Setelah itu akan muncul tampilan login modem. Klik panah bawah dan pilih user.

Pada kolom input password yang muncul, ketikkan user lalu klik tombol GO.

2

Mengganti SSID (Nama Wi-Fi)

Setelah berhasil login, klik menu utama Network di bagian atas.

Kemudian pilih submenu WLAN.

Klik menu Basic Settings di bilah sebelah kiri.

Temukan kolom SSIDname dan ganti teks di dalamnya dengan nama Wi-Fi baru yang Anda inginkan.

Klik tombol SUBMIT di bagian bawah untuk menyimpan perubahan.

3

Mengganti Password Wi-Fi

Masih di halaman WLAN, lakukan langkah berikut untuk mengganti kata sandi:

  • Klik menu Security Settings di bilah sebelah kiri.
  • Temukan kolom WPAPre-shared key, hapus password lama dan ketikkan password baru Anda.
  • Pastikan tipe enkripsi disetel ke TKIP+AES.

Klik tombol SUBMIT untuk menyimpan pengaturan password baru Anda.

4

Restart Modem (Opsional)

Beberapa modem memerlukan proses restart agar perubahan nama dan password dapat diterapkan dengan sempurna. Anda dapat mematikan sakelar power modem di bagian belakang, tunggu sekitar 10 detik, lalu nyalakan kembali.

Konfigurasi Selesai!

Anda telah berhasil mengganti nama SSID dan password Wi-Fi. Pastikan untuk mencatat perubahan tersebut dan hubungkan kembali perangkat Anda menggunakan kata sandi yang baru.

Catatan Penting

JIKA SETELAH GANTI PASSWORD PERANGKAT ANDA TIDAK BISA TERHUBUNG, SILAKAN LUPAKAN JARINGAN (FORGET NETWORK) WI-FI TERSEBUT DI PENGATURAN HP ATAU LAPTOP ANDA TERLEBIH DAHULU.
