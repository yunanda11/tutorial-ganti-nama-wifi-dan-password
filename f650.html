Panduan Ganti Password & SSID Wi-Fi

Langkah mudah mengamankan jaringan internet Jarvis Network Anda (Modem F650) dengan memperbarui nama Wi-Fi dan kata sandi.

Pendahuluan

Mengganti password Wi-Fi dan SSID secara berkala penting untuk menjaga keamanan jaringan Anda . Dalam tutorial ini, Anda akan belajar cara login ke modem, mengubah SSID (nama jaringan Wi-Fi), serta mengganti password Wi-Fi Anda .

1

Login ke Modem/Router

Buka browser Google Chrome dan ketik IP Address berikut di address bar / bagian atas, lalu tekan Search / Cari .

192.168.1.1

Setelah itu muncul tampilan login modem seperti di bawah ini . Masukkan kredensial berikut:

  • Username: user
  • Password: user

Kemudian klik tombol Login .

2

Mengganti SSID (Nama Wi-Fi)

Setelah berhasil login, ikuti alur menu berikut:

  1. Buka menu Network
  2. Pilih WLAN Radio2.4G

Klik menu SSID settings di bilah sebelah kiri .

Temukan kolom SSID Name dan ganti teks di dalamnya dengan nama Wi-Fi baru yang Anda inginkan .

Klik tombol SUBMIT untuk menyimpan perubahan .

3

Mengganti Password Wi-Fi

Langkah-langkah mengganti password Wi-Fi:

  • Klik menu Security di bilah sebelah kiri .
  • Temukan kolom WPA Passphrase dan ganti dengan password baru yang diinginkan .
  • Pastikan enkripsi disetel ke TKIP+AES dan masukkan password baru .

Klik tombol SUBMIT untuk menyimpan perubahan .

4

Restart Modem (Opsional)

Beberapa modem memerlukan restart agar perubahan dapat diterapkan . Anda dapat melakukan restart melalui menu modem atau dengan mematikan dan menyalakan kembali perangkat secara fisik .

Konfigurasi Selesai!

Anda telah berhasil mengganti nama SSID dan password Wi-Fi Anda . Pastikan untuk mencatat perubahan tersebut agar tidak terlupa .

Catatan Penting

JIKA SETELAH GANTI PASSWORD TIDAK BISA COBA LUPAKAN WIFINYA TERLEBIH DAHULU .
